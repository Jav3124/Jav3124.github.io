## 🚀 Website Features

- 🌓 **Dynamic Theme System**: Seamless toggle between Dark and Light mode, persisting user preference.
- 📱 **Fully Responsive**: Mobile-first architecture, optimized for smartphones, tablets, and wide monitors.
- 🖨️ **Print & PDF Ready**: Dedicated `@media print` style sheet — pressing `Ctrl + P` generates an executive 1-2 page clean resume document.
- ⚡ **Zero External Build Step**: Pure HTML5, CSS3, and modern vanilla JavaScript for instant loading and 100/100 Lighthouse performance.
- 📋 **One-Click Contact Copy**: Fast email copying with feedback toasts and direct `mailto:` triggers.
